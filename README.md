## 🧩 什麼是 MklLauncher？

**MklLauncher** 是一款以 Electron 為核心、結合 React + Node.js 所打造的 Minecraft 模組啟動器，支援自定義、模組整合、Forge/Fabric 等載入器安裝，並具備現代化 UI 與錯誤回報功能。

本專案目前為 Beta 階段，歡迎玩家、開發者一同測試、回饋與貢獻。

## 🔧 技術簡介（Technical Overview）

- 💻 使用 **Electron** 實作桌面應用程式
- ⚛️ 前端使用 **React + SCSS**
- 📦 Node.js 為後端模組與檔案管理處理器
- ✅ 支援 Forge / Fabric 模組安裝
- 🖼️ 可預覽材質包與遊戲截圖
- 📡 整合 Discord Rich Presence
- 🐞 內建錯誤回報與日誌系統

---

## 📌 專案目標與定位

MklLauncher 是一個現代化 Minecraft 啟動器，旨在提供簡單但強大的模組化啟動體驗。
